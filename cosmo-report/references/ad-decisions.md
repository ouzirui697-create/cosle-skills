# 广告决策：事实先于标签

## 判读顺序

1. 核对站点、周期、币种、收费状态、归因窗口、重复/缺失与覆盖。
2. 并列总订单、本品订单、其他SKU订单与销售额；无法拆分时说明限制。
3. 按广告实体看曝光→点击→归因，再读问题/回答判断相关性。不用成交倒推语义标签。
4. 对照卖家的阶段、目标、真实贡献利润、预算与目标ACOS给有条件建议。
5. 给验证指标和失败条件；历史样本的候选不等于今天必须执行的动作。

## 三类输出

| 类型 | 条件 | 输出 |
|---|---|---|
| 核查 | 成本缺失、重复、拆分异常、回答型号偏离或范围不明 | 来源、需要核查的事实与补充数据 |
| 观察 | 免费期、样本不足、归因未成熟或目标不明 | 下次观察条件，不报确定加价/停投百分比 |
| 调整候选 | 最新成熟收费期、成本/归因清楚、目标明确且样本与相关性支持 | 广告实体、依据、可控试验动作、损失上限及复查标准 |

review_candidate仅表示数值上可进一步评估，不是加价建议或账户执行授权。
不能补齐参数就放行：1个偶然订单不会因点击够数就变成稳定转化。

## 不再使用的旧规则

- L3 → 暂停：泛品牌问题也会转化，无转化也需看费用、目标和样本。
- 出单 → +20–30%：总归因可能来自其他SKU，免费期0%ACOS不是涨价空间。
- 固定CPC阈值 → 停止：不能推广单个类目/案例的门槛。
- 回答换型号 → Listing缺参数：只能记录回答内容偏离，原因待独立核验。
- 0订单 → Listing差/广告无效：样本、归因延迟、价格库存等都可能影响结果。
- Prompt表现 → 整个Campaign预算调整：Prompt只是活动的一部分，需要完整活动报告。

## 有条件评估

收费且成本完整、转化稳定、ACOS低于卖家目标：核查本品/其他SKU贡献、预算损失和边际成本后，
再考虑小范围扩量试验；幅度依据当前竞价/预算及可承受损失，不固定加价。

成熟收费期ACOS高于目标或无订单：区分相关性、CPC、转化与归因原因，再评估压价、暂停单项或采样。
无销售时ACOS未定义，报告实际花费/点击，不伪造100%或代理值。
需要止损线时用卖家明确的试验预算/可承受损失，不使用类目默认常数。

本品0单、其他SKU有单可能有组合价值，也可能SKU替代；缺购买商品明细/利润时不判盈利或浪费。
回答型号与购买SKU是两类证据，不能互相替代。

## 每项结论

保留活动/广告组ID或名称、ASIN/SKU、问题原文、周期、源表/行号、点击/订单样本、
总花费及总/本品/其他SKU销售可得口径、事实、推断、建议和复查条件。
无分配依据时不捏造本品与其他SKU各自广告费。
注明品类与样本范围，同问题多行不等于独立买家。前后期关联不等于因果验证，
预计节省/提升必须有明确假设与区间，不能承诺收益。

后台可用控制/竞价层级以当前站点官方文档或界面为准，不把Prompt原文当可直接购买/否定的搜索词，
也不假设每个Prompt有独立bid。建议不自动授权改广告，执行依用户明确请求及接口。

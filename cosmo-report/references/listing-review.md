# 可选Listing核验与改写

仅在请求Listing诊断/改写时使用；缺文案不阻断广告分析。

优先用用户提供的当前Title/Bullets和站点/日期，再读产品页并确认有正文。
搜索摘要或Ad Name不能证明完整五点是否包含某信息。需要文案时询问，同时继续广告事实工作。
整理「ASIN、已有原文、建议补充项、来源」供复核，已提供的事实不重复确认。
不虚构缺失，不猜认证/规格。未确认处标「待确认」，回答换型号不直接归因于文案缺陷。

保留局部前后对照与完整Title/Bullets/图片方向/Q&A草稿能力；完整文案按用户需求交付。
字数、认证及站点规则按当前品类核验，不固定通用200字符或必须5条。
不强制每条有数字或capable of。品牌适用时读[brand_profiles.md](brand_profiles.md)，
示例型号与参数不能迁移为当前产品事实。

默认给可验证优点、缺口和来源；停用旧版把Ad Name、回答与Listing混在一起的「真实Rufus分」。
用户需要分数时注明自定义启发式，先列输入、维度、权重、缺失处理、不确定性再算，
缺Listing不打分、不填0。前后变化不等于文案因果效果，不承诺固定时间改变Rufus回答。

# 评分维度细则（Scoring Rubric）

## 主图评分 · 6 维度 · 满分 100

### 维度 1 · Amazon 主图政策合规度（权重 25%）

| 分数 | 锚点 |
|------|------|
| 90-100 | 主图 #1：纯白底 RGB ≥ 252 / 产品占比 85%+ / 像素 ≥ 2000×2000 / 无文字 / 无未售配件 |
| 75-89 | 副图位（#2-9）：合规但非 #1 候选；轻微问题（产品占比 70-85%） |
| 50-74 | 灰底 / 渐变背景（不合规为 #1，但可作副图）；产品占比 60-70% |
| 30-49 | 像素低于 1000×1000（无 Amazon zoom 功能）；产品占比 < 60% |
| 0-29 | 严重违规：含 logo 道具 / 未售配件 / 文字混在主图 |

**关键检查**：
- 主图 #1 候选必须是纯白（取色器确认 RGB ≥ 250）
- 主图 #1 不能含<strong>道具</strong>（如手 / 桌面 / 包装盒），只能是产品本身
- 像素从文件大小粗略估计（74 KB JPG 通常 < 1500×1500，可能不达 zoom 标准）

### 维度 2 · Rufus 多模态视觉典型性（权重 25%）

Rufus 是 multimodal LLM，能 OCR 文字 + 识别产品形态 + 识别屏幕显示 + 识别接口名。

| 分数 | 锚点 |
|------|------|
| 90-100 | 关键数字清晰可 OCR（4.67Gbps / 5765Mbps / 13.5h）+ 产品 spec 视觉化（接口标注 / 屏幕显示）+ 场景人物可识别 |
| 75-89 | 数字 + 产品形态清晰，但缺少屏幕显示等"活的"元素 |
| 60-74 | 仅产品形态清晰，无数字、无文字、无场景细节 |
| 40-59 | 视觉信息模糊 / 抽象图过度（如纯概念光道 + 一个产品悬浮） |
| 0-39 | Rufus 无法识别产品类型 / 内容混乱 |

**关键检查**：
- 屏幕显示是 Rufus 视觉锚点高分点（数字钟 / 天气图 / SIM 切换 UI 都能命中 prompt）
- 文字过小（移动端缩略图不可读）扣分
- 抽象概念图（纯光道无产品细节）扣分

### 维度 3 · 视觉清晰度 & 信息层级（权重 20%）

| 分数 | 锚点 |
|------|------|
| 85-100 | 主标题 / 副标题 / 数字三级层级清晰；视觉焦点单一；移动端 1/4 缩略图仍可读关键文字 |
| 70-84 | 主标题清晰但副标题略密；视觉焦点 2-3 个（中等） |
| 55-69 | 文字密度高 / 字号偏小 / 移动端缩略图开始读不清 |
| 40-54 | 信息超载 / 9+ 元素挤压 / 字 < 14pt 等价 |
| 0-39 | 过曝 / 字密到完全不可读 / 视觉重心混乱 |

### 维度 4 · 差异化卖点呈现（权重 15%）

<strong>依赖上游 prelaunch-listing 报告识别的 N 个独家差异化点</strong>。如果没有上游报告，按本品类的通用差异化标准（如路由器：Wi-Fi 标准 / 5G 芯片代 / SIM 模式 / VPN 速度 / 触屏交互）。

| 分数 | 锚点 |
|------|------|
| 90-100 | 视觉化呈现 ≥ 5 个独家差异化点（数字 + 图示双重证据） |
| 75-89 | 视觉化 3-4 个独家差异化点 |
| 60-74 | 视觉化 1-2 个独家差异化点（含数字） |
| 40-59 | 仅文字暗示，无视觉证据 |
| 0-39 | 完全没体现差异化 |

### 维度 5 · 场景 / 人群代入感（权重 10%）

仅对场景图打分（产品图标记 n/a 不参与）。

| 分数 | 锚点 |
|------|------|
| 85-100 | 场景与上游 Tier 1-3 用户对齐 ≥ 80%；人物多元（性别 / 种族 / 年龄）；环境真实 |
| 70-84 | 场景对齐 60-80%；人物单一职业向 |
| 55-69 | 场景通用（任何品类都可用），未针对目标用户 |
| 40-54 | 场景与目标用户错位 |
| 0-39 | 摆拍痕迹明显 / 场景虚假 |

### 维度 6 · 品牌一致性（权重 5%）

| 分数 | 锚点 |
|------|------|
| 85-100 | 配色 / 字体 / 视觉语言与品牌 KV 完全一致 |
| 60-84 | 主色一致，细节风格略偏 |
| 40-59 | 视觉风格断裂（如某张图色调与其他图反差极大） |

## A+ 图片评分 · 5 维度 · 满分 100

### 维度 1 · 信息层级 & 版式（权重 25%）

| 分数 | 锚点 |
|------|------|
| 90-100 | 适配 A+ 横版 1464×600 / 信息中心明确 / 与主图 & 其他 A+ 模块<strong>不重复</strong> |
| 75-89 | 版式专业，无重复 |
| 60-74 | 版式合格，但与主图 / 其他 A+ 有部分内容重叠 |
| 45-59 | 与主图 / 其他 A+ 模块<strong>高度重复</strong>（如 9 宫格同时出现两次） |
| 0-44 | 版式混乱 / 信息中心缺失 |

**关键检查**：与主图 / 其他 A+ 模块重复直接扣 10-15 分。

### 维度 2 · Rufus 抓取友好度（权重 25%）

| 分数 | 锚点 |
|------|------|
| 85-100 | A+ 中所有关键文字 Rufus 都能 OCR / 视觉补充了 Title/Bullet 未传达的卖点 |
| 70-84 | OCR 友好，但内容与 Bullet 重叠多 |
| 55-69 | OCR 友好度中（部分字小或对比度低） |
| 40-54 | 关键文字字号过小 / 颜色对比度差 |

### 维度 3 · 文字密度 & 移动端可读性（权重 20%）

Amazon A+ 在移动端压缩 50%，正文等价 14pt 是底线。

| 分数 | 锚点 |
|------|------|
| 85-100 | 主标题 ≥ 32pt / 副标题 ≥ 20pt / 正文 ≥ 14pt 等价 |
| 70-84 | 主标题适中，正文 12-14pt |
| 55-69 | 正文 10-12pt（移动端勉强可读） |
| 40-54 | 正文 < 10pt（移动端不可读） |

### 维度 4 · 场景连贯性 & Tagline 一致性（权重 15%）

| 分数 | 锚点 |
|------|------|
| 85-100 | A+ 跨模块 tagline 一致；与上游 prelaunch-listing 报告引用的 Tier 营销 tagline 完全对齐 |
| 70-84 | tagline 基本一致，个别模块用了泛化短语 |
| 55-69 | 模块间 tagline 风格断裂 |
| 0-54 | tagline 与上游报告完全不对齐 |

### 维度 5 · 品牌一致性 & 设计质感（权重 15%）

| 分数 | 锚点 |
|------|------|
| 85-100 | 设计奖徽章 / 认证 logo 合理使用 / 视觉语言与 KV 完全一致 |
| 70-84 | 视觉一致，设计质感专业但无信任锚 |
| 55-69 | 视觉一致度中等 |

## 评分常见扣分场景（速查表）

| 场景 | 扣多少 | 说明 |
|------|--------|------|
| 主图 #1 候选不是纯白底 | -40 维度 1 | 直接不合规为 #1 |
| 像素 < 1000×1000 | -20~-30 维度 1 | Amazon zoom 不支持 |
| 产品占比 < 60% | -15~-20 维度 1 | 视觉留白过多 |
| 主图间内容重复（同款角度） | -10 维度 4 | 浪费主图位置 |
| 主图与 A+ 内容重复 | -10 维度 4（主图） + -10~-15 维度 1（A+） | 双向扣分 |
| 文字 < 10pt 等价 | -15 维度 3 | 移动端不可读 |
| 缺独家差异化 | -10~-15 维度 4 | 视具体缺哪个点 |
| 场景与 Tier 用户错位 | -15 维度 5 | 仅对场景图 |
| 文件命名冲突（多个 9 号） | 单独说明，不直接扣分 | 必须改名 |

# Amazon 主图与 A+ 政策摘要

## 主图 #1（强制要求）

Amazon 对主图 #1 的政策非常严格，违反会导致 listing 被算法降权或直接拒绝：

| 项 | 要求 |
|----|------|
| 背景 | 纯白底 RGB(255, 255, 255)（实测容忍 RGB ≥ 250） |
| 产品占比 | ≥ 85%（视觉留白宽边 ≤ 15%） |
| 像素 | ≥ 1000×1000（支持 zoom 功能）；推荐 ≥ 2000×2000 |
| 内容 | 仅展示售卖商品本身 |
| 禁止 | 文字 / logo 水印 / 道具（手、桌面、包装盒）/ 未售配件 |
| 边缘 | 产品完全在框内，不切边 |
| 阴影 | 自然轻微阴影 OK；过深 / 反光 / 渐变扣分 |
| 格式 | JPEG / PNG / GIF / TIFF（PNG 用于透明底较常见） |

## 副图 #2-#9（自由度高）

副图位（#2 到 #9）没有 #1 那么严格，可以：

- 加文字 / 图标 / 数字标注
- 加场景背景（lifestyle / 户外 / 工作室）
- 加对比图 / 9 宫格 / 表格
- 加道具（手 / 笔记本 / 咖啡杯等情境物）
- 加 Lifestyle 模特图
- 加爆炸图 / 透视图

但仍然禁止：
- 含价格、促销、Prime 徽章等 Amazon 平台元素
- 含违反广告法的极端用词（"100% safe" / "doctor recommended" 等）
- 含未售配件（除非另列在 listing）

## 主图序列推荐结构（高转化路径）

| 位置 | 角色 | 典型内容 |
|------|------|---------|
| #1 | 白底主图 | 产品 3/4 视角，无文字，纯白底 |
| #2 | 副角度 / 正反对应 | 产品另一面 / 俯视 / 立面 |
| #3 | 尺寸 / 接口图 | 三维尺寸标注 + 所有接口名 |
| #4 | 9 宫格特性总览 | 集中呈现 6-9 个核心 spec |
| #5-#6 | 独家差异化单点放大 | 每张图聚焦 1 个独家差异化点 |
| #7 | 场景图 | Tier 1-3 用户场景代入 |
| #8 | 对比图 / 信任锚 | vs 竞品对比 / 认证 logo / 设计奖 |
| #9 | Inside the Box | 包装清单 / 心理预期管理 |

## A+ Content 模块尺寸

Amazon A+ Standard / Brand 模块的常见尺寸：

| 模块 | 尺寸 (px) | 用途 |
|------|----------|------|
| Hero / KV | 1464×600 | 顶部首屏（含品牌 logo + 主标题 + 副标题 + 产品） |
| Image Banner（横版） | 1464×600 | 大横版图（场景 / 概念 / 9 宫格亮点） |
| Image-Text 双列 | 600×450（左图） + 文字 | 单点放大（左图 + 右文字） |
| Image-Text 四列 | 220×220×4 | 4 列方格（图标 + 标题 + 数字） |
| Comparison Chart | 表格组件 | vs 竞品 / vs 自家上代 |
| Brand Story | 1464×625 | 品牌故事模块（Brand Registry 卖家专属） |

## 移动端缩略图压缩

Amazon 在移动端：
- 主图序列显示为 1/4 大小缩略图（200×200 等价）
- A+ 模块整体压缩 50%，且部分模块横向滚动
- 正文字号 < 14pt 等价在移动端不可读 — A+ 评分时必须考虑

## 区域差异（NA / EU / UK / JP）

- 5G / LTE 频段表必须按区域专版（NA n2/n7/n66... vs EU n1/n3/n28...）
- A+ 中的认证 logo 按区域区分（CE 用于 EU / FCC 用于 NA / PSE 用于 JP）
- 营销 tagline 不能照搬翻译，需本地化

## 视频 / Posts / Brand Store / Brand Story

以下不在本 skill 评分范围（建议另行评估）：

- 产品视频（Amazon Video Catalog）
- Amazon Posts
- Brand Store
- Brand Story 模块（Brand Registry 卖家专属）

如果用户提及这些资产，明确告知超出范围。

## 政策更新追踪

Amazon 主图 / A+ 政策每季度更新，本文件基于 2026 Q1 状态。如有疑问，参考：
- Amazon Seller Central → Help → "Product image requirements"
- Amazon Brand Registry → A+ Content Guidelines
